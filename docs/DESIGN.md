# ReinChat · Liquid Glass Design Notes

## 1. 设计意图

ReinChat 的核心视觉不是“深色主题 + 毛玻璃卡片”，而是一个**会呼吸的光场**：

- 背景始终比前景更亮、更有色彩；
- 表面只负责把背景折射进界面，而不是遮住背景；
- 所有运动共享同一组曲线，避免不同组件各自动、互相打架；
- 信息层级靠字号、留白、透明度建立，而不是靠粗重的分隔线。

首个可用版本采用深色单主题，这是为了保证半透明图层在任何壁纸/系统主题下都有稳定的对比度。

## 2. 色彩

| Token | Value | 用途 |
| --- | --- | --- |
| `Deep` | `#050807` | 画布基底 |
| `Mint` | `#8BF3CE` | 主强调色、发送、当前服务商 |
| `Cyan` | `#84D8F5` | 渐变第二色、链接 |
| `Violet` | `#BCA7FF` | 极光尾色、Responses 标签 |
| `Warm` | `#F4D9AD` | 极光中的暖色偏移、未配置提醒 |
| `TextPrimary` | `#F4F8F6` | 正文 |
| `TextSecondary` | `#A6B3AE` | 辅助信息 |
| `TextTertiary` | `#6E7B76` | 时间戳、占位 |

极光背景中的色块使用更饱和的绿/蓝/紫，经过 `radialGradient + 低透明度` 进入深色底，形成类似玻璃折射的淡色光晕。文本区域上方会叠加轻微暗化，保证可读性。

## 3. 玻璃表面

`Modifier.liquidGlass` 是所有表面的基础：

1. 按形状裁剪；
2. 从上到下的白色半透明渐变（约 5–12% alpha）；
3. 1dp 彩色渐变边框：白 → Mint → 低白 → Violet；
4. 顶部高光渐变和 1px 镜面线；
5. 可选彩色环境阴影，用于 Composer 和当前服务商卡片。

`GlassSurface`、`GlassInputField`、`GlassDialog` 都复用同一套量级，避免“每张卡都长得不一样”。

## 4. 运动

| 名称 | 曲线 / 参数 | 用途 |
| --- | --- | --- |
| `LiquidEase` | `cubic-bezier(0.16, 1, 0.30, 1)` | 页面进入、抽屉、气泡入场 |
| `LiquidEaseInOut` | `cubic-bezier(0.65, 0, 0.35, 1)` | 光标呼吸、输入焦点 |
| `LiquidEaseOutSoft` | `cubic-bezier(0.22, 0.61, 0.36, 1)` | 菜单高度、底部按钮 |
| 按压弹簧 | `dampingRatio 0.68, stiffness 720` | 圆形工具按钮、主按钮 |
| 慢极光 | 16s / 42s infinite | 背景光场 |

原则：

- 进入比退出慢约 100–200ms；
- 小元素用弹簧，大面板用 bezier；
- 同一屏幕上同时运动的元素不超过 2 组；
- 内容流式更新时不再播放额外位移动画，只保留光标。

## 5. 聊天布局

- 用户消息：右对齐、宽高随内容、右下角收角（7dp），强度更高的薄荷玻璃；
- AI 消息：不套气泡，只保留“头像 + 名称 + 正文”的浮层结构，让长文更轻；
- 每条消息底部有低对比时间戳和三点入口；
- **整块消息点按也能展开操作托盘**，一次只允许一条消息展开；
- 操作托盘为胶囊玻璃，包含复制、编辑、回退到此处；
- 回退后展示 Snackbar 撤销；
- 图片消息支持 1 张大图或 2×2 网格；
- 从底部开始反向布局，最新消息优先可见；
- 用户向上滚动后显示“回到最新”浮珠。

## 6. 输入区

- 常驻悬浮玻璃 Composer，带轻微底部薄荷光晕；
- 编辑态显示“正在编辑之前的提问”并自动聚焦键盘；
- 附件以 58dp 玻璃缩略图排列，最多 4 张；
- 发送按钮在 idle 时是薄荷渐变圆形，生成中 morph 成玻璃 Stop；
- 输入框最高 6 行，超出内部滚动；
- 服务商 chip 位于左下，右下为“端侧直连”状态点。

## 7. 会话与服务商

- 会话抽屉从左侧 spring-like 滑入，主界面在 12–14dp 模糊后作为背景；
- 会话条目只在激活时增加极淡背景和边框；
- 服务商卡片用协议色（Responses 紫 / Chat 青）和当前使用对勾建立层级；
- 服务商编辑页为独立沉浸层，底部固定保存按钮，保证长表单可达。

## 8. 账户与云端

- 账户卡片固定在设置页顶部，先说明“登录后能做什么”，再展示登录按钮；登录后显示用户名、服务器和同步状态；
- 登录/注册页沿用液态玻璃，但使用完整页面而非 Dialog，避免键盘顶起时表单被压缩；
- 新会话的云端开关只出现在空会话首屏，默认开启（已登录）；开启后文案明确“不可关闭”，从交互层保证不可逆；
- 云端/仅本地状态使用极淡的云朵图标和副标题后缀，不新增高对比度标签；
- 服务商的“仅保存在本机”开关关闭时，用薄荷色说明会同步 API Key；未登录时固定开启且禁用；
- 云端同步的失败信息进入账户卡片，而不是打断对话；删除云端会话时先写入待删除列表，避免离线删除被下次同步“复活”。

## 9. 可访问性与兼容

- 所有纯图标按钮都有中文 contentDescription；
- 正文 16sp / 27sp 行高，辅助信息最低 9.5sp 但不承担关键操作；
- 触摸目标 ≥ 40dp（三点入口 28dp 视觉，外层行内留白扩大有效区域）；
- 不依赖 GMS、动态颜色或 Android 12+ 特性；`Modifier.blur` 在旧系统自动失效；
- 图片选择优先 Photo Picker，回退 SAF；
- 为卓易通兼容层特别移除了对 AndroidKeyStore 跨进程持久化的强依赖。
